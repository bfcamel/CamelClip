# MacDown

Небольшая консольная программа на Go для macOS. При запуске без параметров задаёт вопросы на русском. Скачивание выполняет **yt-dlp**: поддержка YouTube, VK и других сайтов зависит от его актуальной версии и доступности конкретного ролика.

## Установка и сборка

Если Homebrew уже установлен:

```sh
brew install go yt-dlp ffmpeg deno
```

Homebrew: https://brew.sh/

В Терминале перейдите в папку с этим README и выполните:

```sh
go build -o macdown .
./macdown
```

После сборки можно открывать `Start.command` двойным щелчком в Finder. Откроется Терминал с простым меню: вставьте ссылку, выберите `1` (видео со звуком) или `2` (только звук), затем качество/формат и папку. Enter оставляет значение по умолчанию.

Сборки сразу для Apple Silicon и Intel:

```sh
sh build.sh
```

Результат появится в `dist/`: `macdown-macos-arm64` для Apple Silicon (M1 и новее), `macdown-macos-amd64` для Intel и `Start.command`. Эту папку можно перенести на другой Mac. Ему тоже нужны yt-dlp, FFmpeg и Deno; Go нужен только для сборки. В скачанном готовом архиве сборки могут лежать рядом с исходниками. Запуск из Терминала: `./macdown-macos-arm64` или `./macdown-macos-amd64`.

Репозиторий содержит исходники; исполняемые файлы и локальные загрузки исключены из Git.

## Примеры

Видео со звуком, максимум 1080p:

```sh
./macdown -url 'https://www.youtube.com/watch?v=VIDEO_ID' -quality 1080
```

Лучшее доступное качество:

```sh
./macdown -url 'https://vk.com/video-OWNER_ID_VIDEO_ID' -quality best
```

Только звук в MP3:

```sh
./macdown -url 'ССЫЛКА' -mode audio
```

Аудио без принудительного перекодирования в другой формат:

```sh
./macdown -url 'ССЫЛКА' -mode audio -audio-format best
```

Своя папка:

```sh
./macdown -url 'ССЫЛКА' -out "$HOME/Movies/Downloads"
```

Показать форматы, которые предлагает сайт, без скачивания:

```sh
./macdown -url 'ССЫЛКА' -formats
```

Если ролик требует входа в ваш аккаунт, можно явно разрешить использование cookies браузера, где вы уже вошли:

```sh
./macdown -url 'ССЫЛКА' -cookies-browser firefox
```

Также поддержаны safari, chrome, edge, brave. macOS может запросить доступ к данным браузера. По умолчанию программа cookies не читает.

Справка: `./macdown -h`. Остановка: Ctrl+C.

## Поведение и ограничения

- По умолчанию файлы сохраняются в `~/Downloads/MacDown`.
- Видео сохраняется со звуком в MKV без перекодирования. Контейнер подходит для разных кодеков; для воспроизведения можно использовать VLC. Совместимость с QuickTime не гарантируется.
- Качество — максимальная высота исходного кадра. При выборе 1080 скачивается лучшее доступное разрешение не выше 1080; увеличение разрешения не выполняется. Если подходящих потоков со звуком нет, скачивание завершается ошибкой. Для вертикального видео это тоже именно высота кадра.
- Аудиоформаты: mp3 (по умолчанию), m4a, opus, flac, wav, best. Перекодирование в FLAC/WAV не улучшает исходное качество звука.
- Скачивается один ролик, а не плейлист. Отдельного выбора дорожек и субтитров пока нет.
- Готовые файлы не перезаписываются; незавершённую загрузку yt-dlp пытается продолжить при повторном запуске той же команды.
- DRM, ограничения аккаунта и недоступность ролика программа не устраняет. Прямые трансляции могут скачиваться до остановки.
- Настройки пользователя из конфигурации yt-dlp игнорируются для предсказуемого поведения.
- Для актуальной поддержки YouTube нужны JavaScript runtime (рекомендуется Deno) и yt-dlp-ejs. Если yt-dlp сообщает об отсутствии EJS, проверьте установку по официальной инструкции ниже.

При сбоях после изменений сайтов обновите зависимости:

```sh
brew upgrade yt-dlp ffmpeg deno
```

Документация: https://github.com/yt-dlp/yt-dlp#readme

Поддержка YouTube EJS: https://github.com/yt-dlp/yt-dlp/wiki/EJS

## Проверка исходников

```sh
go test ./...
go vet ./...
```

Go-программа использует только стандартную библиотеку. URL и параметры передаются yt-dlp отдельными аргументами без запуска shell.
